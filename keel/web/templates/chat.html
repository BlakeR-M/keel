Keel

What it is. A retrieval and agent appliance that runs where the documents live: one machine on premise, or a client's own Azure tenancy. This demo is the on-premise build with a small CPU model.

What it is for. A team asks questions of its own documents and gets answers citing the exact chunk they came from. The permission filter sits inside retrieval, so each person sees what their role allows and the model sees only entitled chunks.

How it is built. Hybrid BM25 and vector retrieval, fused and reranked, with the permission filter applied before fusion. A local model generates, and every request lands in a hash-chained ledger the admin page can verify.

How it runs internal operations. Agent mode calls five typed tools under a written policy: document search, a calculator, read-only SQL, an allowlisted HTTP GET that refuses outright under air-gap, and ticket creation. Write actions wait in an approval queue for a person, and every step is audited.

Hosted demonstration of the fixture corpus, five documents holding nothing real. The permission comparison runs on the overview page, where the same restricted question is asked as two users side by side. About this demo
